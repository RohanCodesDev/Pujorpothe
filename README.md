## ✨ Features

- 🗺️ **Interactive Pandal Map**: A beautifully integrated Leaflet map with 70+ meticulously hand-mapped real-world GPS coordinates for Kolkata's most iconic Durga Puja clubs.
- 📍 **Smart GPS Sorting**: Uses the Haversine formula to instantly sort 130+ pandals by their real-time physical distance from your current location.
- 🚇 **Metro Navigator**: Seamlessly filter pandals by proximity to Kolkata's Blue, Green, Orange, and Purple Metro lines.
- 📱 **Progressive Web App (PWA)**: Fully installable on iOS and Android. Built with a custom native Service Worker to ensure fast loading during heavy festival network congestion.
- 🎨 **Premium UI/UX**: Designed with a stunning, ultra-modern dark aesthetic featuring frosted glass modals (glassmorphism), smooth micro-animations, and curated bilingual typography (English + Bengali).
- 🧭 **Curated Trails**: Pre-built exploration circuits like the "South Kolkata Night Trail", "Heritage & Bonedi Trail", and "Art Lover's Circuit".

## 🚀 Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router & Turbopack)
- **Library**: [React 18](https://reactjs.org/)
- **Maps**: [Leaflet.js](https://leafletjs.com/) with custom dark-mode tile filtering
- **Styling**: Pure Vanilla CSS (`index.css`) optimized for high-performance fluid layouts
- **PWA**: Custom Service Worker (`sw.js`) and Web Manifest

## 🛠️ Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/RohanCodesDev/Pujorpothe.git
   ```
2. Navigate into the project directory:
   ```bash
   cd Pujorpothe
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Start the development server using Turbopack:
   ```bash
   npm run dev
   ```
5. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📱 PWA Installation (Mobile)
To install PujorPothe on your phone as a native app:
1. Open the deployed URL in Safari (iOS) or Chrome (Android).
2. Tap the **Share** button (iOS) or the **Three Dots** (Android).
3. Select **"Add to Home Screen"**.
4. The app will now launch in standalone full-screen mode!
